# Primeiro Projeto — UNES

Meu primeiro site: um modelo de página institucional para uma universidade fictícia, feito com HTML e CSS.
My first website: a template for a fictional university's homepage, built with HTML and CSS.

[🇧🇷 Português](#-português) · [🇺🇸 English](#-english)

---

## 🇧🇷 Português

### Sobre o projeto

Primeiro projeto que publiquei no GitHub. É um site de três páginas para a "UNES", uma universidade fictícia: **Home**, **Quem somos** e **Contato**. Os textos são de preenchimento (lorem ipsum). O objetivo foi praticar a estrutura de páginas, os links entre elas e a estilização básica.

### Tecnologias

- HTML5
- CSS3

### Como usar

Baixe o repositório e abra o `index.html` no navegador.

### Estrutura

```
index.html       página principal
quemsomos.html   sobre a universidade
contato.html     página de contato
img/             imagens
```
